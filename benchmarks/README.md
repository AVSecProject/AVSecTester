# Benchmarks

This directory does not yet contain a bundled benchmark suite or a published benchmark adapter.

Researchers can define scenario sets with [scenario selection](../docs/guides/scenarios.md) and run
[robustness evaluation](../docs/guides/evaluation.md#robustness-across-corruption-settings). A
benchmark additionally needs a specified scenario source, selection filters, operating conditions,
driving system, intervention settings and scoring criterion. The existing stop-based impact metric does not define success for every attack.

See [Implementation status](../docs/concepts/architecture.md#implementation-status) for current
capabilities and the [README](../README.md#status) for longer-term goals.
