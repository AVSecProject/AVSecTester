# Benchmarks

**Not yet implemented.** A bundled benchmark suite or published benchmark adapter.

An experiment configuration can define datasets, Attack metadata selection, driving systems,
treatments, environments and log-based metrics. A reproducible benchmark additionally needs
published scene membership, model versions, artifact identities and a scientific scoring protocol.
A completed workflow alone does not define attack success.
