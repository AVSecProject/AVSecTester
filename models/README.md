# Model checkpoints

This directory holds local model weights and assets; binaries are excluded from git.
[Installation](../docs/getting-started/installation.md) owns model sources, preparation
commands, container mounts and the trafficsim weight checks.

The supplied [driving systems](../docs/guides/driving-systems.md) describe their model
interfaces. [Configurations](../docs/examples/README.md) select the models for each experiment.
