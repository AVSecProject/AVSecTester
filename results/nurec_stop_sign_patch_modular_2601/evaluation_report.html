How to read this report

A treatment is one configured execution condition. Clean means no attack. A comparison group contains the same segment and seed: all treatments start from the same initial state. A part is a dataset split: train, validation or test.

Run status is completed when execution finishes successfully. Failed means an execution error. Cancelled means execution was interrupted. Incomplete means execution has not finished. Only completed runs contribute measurements to summaries.

Numerical summaries show mean ± population standard deviation (ddof = 0). n is the number of groups with an available value. Standard deviation is omitted when n < 2. Boolean summaries show the fraction that are true, followed by the true count and total group count.

A paired difference is B − A, calculated within each group before summarizing. Booleans are subtracted as 1 and 0, so their mean difference is a difference in proportions.

— means unavailable. The reasons are listed in Group details. Decimal values are shown with four decimal places. Whole-number counts are shown as integers. JSON and CSV keep full precision.
